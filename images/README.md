# Images Directory

This directory contains the images used in the portfolio website.

## Required Images

1. **profile.jpg** - Your main profile picture (recommended size: 500x500 pixels)
2. **user-logo.png** - Your user logo/brand image (recommended size: 200x200 pixels)

Please add these images to this directory to ensure the website displays correctly.

## Image Guidelines

- Use square images for best results with the circular cropping
- Ensure images are optimized for web (compressed without losing quality)
- For the user logo, consider using a transparent PNG for better integration with the design
